# Corvo image assets

Place the supplied brand and project images in this folder using these exact filenames.

## Required files

### `corvo-logo.svg`

- The exact Corvo Technologies logo supplied by the brand owner.
- Preferred format: SVG with a transparent background.
- The logo should include the complete lockup if that is how the supplied logo is delivered.
- Used in: the desktop header, mobile header, and footer.
- Recommended artboard: approximately 760 x 160 px, with minimal transparent padding.

### `corvo-hero.jpg`

- A wide, high-quality image showing the company, team, product, or technology environment.
- Used in: the large hero image on the homepage.
- Recommended size: 1600 x 1100 px or larger.
- Recommended format: JPG or WebP.
- Composition: keep the important subject toward the center or right side; the image is cropped responsively.

### `projects/ai-media-content-generator.png`

- The real deployed screenshot for the AI Media & Content Generator project.
- Place this file inside `public/images/projects` using this exact filename.
- Recommended format: PNG or WebP, with the full interface visible and no browser chrome if possible.

### `work-ai.jpg`

- A visual for an AI, automation, chatbot, or intelligent workflow project.
- Used in: the first selected-work tile on the homepage.
- Recommended size: 1200 x 900 px or larger.
- Recommended format: JPG or WebP.

### `work-platform.jpg`

- A visual for a SaaS product, dashboard, CRM, backend, or business platform.
- Used in: the second selected-work tile on the homepage.
- Recommended size: 1200 x 900 px or larger.
- Recommended format: JPG or WebP.

### `work-mobile.jpg`

- A visual for a mobile app or customer-facing digital product.
- Used in: the third selected-work tile on the homepage.
- Recommended size: 1200 x 900 px or larger.
- Recommended format: JPG or WebP.
